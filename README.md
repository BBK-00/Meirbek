# Surface · Live сабақ платформасы

Сабақ беті (анимация, зертхана, ойын, практика, тест) + студент кіруі + мұғалімнің live тақтасы.

**Ағын:** мұғалім `teacher.html` ашып «Сабақты бастау» басады, экранда 4 таңбалы код шығады →
студент `index.html` ашып «Студент» таңдайды, кодты, аты-жөнін, тобын жазады → сабақты өтеді →
практикада орындаған критерийлерді белгілеп «Тапсырманы жіберу» басады (мұғалім шақырылады) →
мұғалімнің тақтасында шақыру кезегі пайда болады → мұғалім 3ds Max-ты тексеріп, критерийлерді растап «Мақұлдау» басады →
балл студентке де, кестеге де түседі.

## Файлдар

| Файл | Не үшін |
|---|---|
| `index.html` | Студенттер мен мұғалім ашатын сабақ беті |
| `teacher.html` | Мұғалімнің live тақтасы (код, кезек, кесте, CSV) |
| `config.js` | **Бапталатын жалғыз файл**: Firebase мәндері және мұғалім құпиясөзі |
| `common.js` | Тапсырмалар, критерийлер, баға шкаласы |
| `db.js` | Деректер қабаты: Firebase немесе DEMO режимі |
| `firestore.rules` | Firestore ережелері |
| `src/` | `index.html`-дің бастапқы бөліктері. Өзгерткеннен кейін `python3 src/build.py` іске қосыңыз |
| `tests/t_flow.js` | Playwright тесті (толық ағын) |

## 1. Firebase баптау (бір рет, ~5 минут)

1. https://console.firebase.google.com → **Add project** (Analytics керек емес).
2. **Build → Firestore Database → Create database**. Аймақ: `eur3` немесе `europe-west`.
3. **Rules** бөліміне `firestore.rules` мазмұнын қойып, **Publish** басыңыз.
4. **Project settings (⚙) → General → Your apps → Web (`</>`)** → қолданбаны тіркеңіз. Шыққан `firebaseConfig` ішіндегі `apiKey`, `authDomain`, `projectId`, `appId` мәндерін `config.js` ішіне қойыңыз.
5. `config.js` ішінде `teacherPassword` мәнін өз құпиясөзіңізге ауыстырыңыз.

Firebase бапталмаса, сайт **DEMO режимінде** жұмыс істейді: деректер тек бір браузерде сақталады (сынау үшін ыңғайлы).

## 2. GitHub Pages-ке жариялау

1. GitHub-та жаңа репозиторий ашып, осы папканың барлық файлын жүктеңіз.
2. **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save**.
3. Бір минуттан кейін сайт `https://<аккаунт>.github.io/<репозиторий>/` мекенжайында ашылады.
   Студенттерге `index.html` сілтемесін (немесе QR-кодын) беріңіз, өзіңіз `teacher.html` ашыңыз.

Жергілікті сынау: папкада `python3 -m http.server 8000` → `http://localhost:8000/teacher.html`.

## 3. Сабақ күні

1. Проекторға `teacher.html` шығарыңыз, құпиясөзбен кіріңіз, **Сабақты бастау** басыңыз. Экранда код пайда болады.
2. Студенттер кодты, аты-жөнін, тобын енгізіп кіреді. Саны «Кірді» жазуында көрінеді.
3. Практика кезінде **Шақыру кезегі** толады. Әр картада: студент белгілегендер (көгілдір жиек), жұмсаған уақыт (норма 18 / 7 / 5 мин), «тым тез» және «уақыттан асты» белгілері. Критерийлерді түзетіңіз, баллды қолмен өзгертуге болады, **Мақұлдау** немесе **Қайтару** (түсініктемемен).
4. Кестеде **Қатысым** бағанына 0–40 балл енгізіңіз, жалпы баға мен әріптік баға автоматты шығады. **CSV** батырмасы нәтижені Excel-ге жүктейді.
5. **Тақта көрінісі**: проекторға тек код пен кестені қалдырады.
6. Сабақ аяқталғанда **Сабақты аяқтау**: жіберу жабылады, деректер сақталады.

Сабақ ішінде мұғалім құралдары (таймер, жазбалар, дөңгелек, журнал) да бар: `index.html` ашып «Мұғалім» рөлін таңдаңыз (құпиясөз сол).

## Бағалау

Барлығы 100 балл: қатысым 40 (мұғалім қолмен қояды) + тапсырмалар 60 (Жапырақ 30, Гүл құмырасы 18, Қасық 12).
Тапсырма балы: мұғалім растаған критерийлердің қосындысы. Критерийлер `common.js` мен `src/page.html` ішіндегі `PRAC` массивінде, екеуін бірдей ұстаңыз.
Практика 30 минут: Жапырақ 18, Құмыра 7, Қасық 5. Тез жіберу шегі: нормаға қатысты 40% (`common.js`, `FAST_RATIO`).

## Қауіпсіздік туралы (маңызды)

- Код пен құпиясөз «сынып деңгейінде» қорғайды. Firestore ережелері ашық (`firestore.rules`), сондықтан тапқыр студент дерекқорды браузер консолінен өзгерте алады. Бір сабаққа жеткілікті, ресми емтиханға жарамайды. Қатаң қорғаныс керек болса, Firebase Authentication немесе серверлік тексеру қосу керек.
- `teacherPassword` `config.js` ішінде ашық жазылған, оны студенттер сайт көзінен көре алады. Оны сабақтан кейін ауыстырып отырыңыз.
- Студенттің аты-жөні кодпен кіргенде өзі жазады, тізім жоқ. Бір атпен екі адам кірсе, бір жазбаға түседі.
- Кіргеннен кейін бет жаңартылса, студент ішке қайта кірмейді (сессия сақталады). Жаңа сабақ басталса, қайта кіреді.
- Firebase-ке нақты қосылу жолы осы жинақта браузерде сыналған жоқ: DEMO режимі толық сыналды, ал `db.js` ішіндегі Firebase бөлігі стандартты Firestore қоңырауларынан тұрады. Бірінші сабақтан бұрын 2 құрылғымен сынап көріңіз.
